# Football Team Management System ⚽

A Java-based Football Team Management System developed using Object-Oriented Programming concepts.

## Features
- Add Player
- Search Player by ID
- Search Player by Name
- Delete Player
- Display All Players

## OOP Concepts Used
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
  - Method Overriding
  - Method Overloading

## Additional Features
- ArrayList for dynamic player storage
- User input handling
- Custom Exception Handling
- Data Validation

## Project Structure

```text
Football-Team-Management-System

├── Main.java
├── Person.java
├── Player.java
├── PlayerOperation.java
├── TeamManagement.java
└── InvalidPlayerException.java
```

## Technology
- Java
- Object-Oriented Programming

- ## How to Run

1. Clone this repository
2. Open the project in any Java IDE
3. Compile all Java files
4. Run `Main.java`

Example:

```
javac Main.java
java Main
```
