# Football Team Management System ⚽

A Java-based Football Team Management System developed using Object-Oriented Programming concepts.

## Features
- Add Player
- Search Player by ID
- Search Player by Name
- Delete Player
- Display All Players

## OOP Concepts Used
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
  - Method Overriding
  - Method Overloading

## Additional Features
- ArrayList for dynamic player storage
- User input handling
- Custom Exception Handling
- Data Validation

## Project Structure

Main.java
Person.java
Player.java
PlayerOperation.java
TeamManagement.java
InvalidPlayerException.java

## Technology
- Java
- Object-Oriented Programming
